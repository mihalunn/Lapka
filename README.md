# Lapka

Учебный pet-проект: семейное веб-приложение для хранения истории питомцев и планирования ухода.

Сейчас репозиторий находится на стадии product discovery. Код приложения ещё не создавался: сначала зафиксированы проблема, MVP, сценарии, дизайн-направление и архитектурные решения.
