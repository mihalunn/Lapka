# ADR-004: Формы через React Hook Form и Zod

Дата: 2026-10-07. Статус: accepted. Подтверждено владельцем: 2026-10-07.

## Контекст

MVP содержит формы питомца, записи истории и календарного события. Им нужны
значения, touched/dirty, клиентские ошибки, состояние отправки и сохранение
введённых данных после исправимой ошибки.

Ручное управление каждым полем через отдельный React state создаст много
однотипного кода. Независимые правила UI и API могут разойтись.

## Решение

- React Hook Form владеет состоянием формы.
- Zod описывает схему и проверяет данные формы.
- Те же схемы или совместимые с ними схемы проверяют ответы mock API на границе.
- Серверные field errors преобразуются в ошибки соответствующих полей.
- API mutation выполняется через RTK Query, но значения формы не переносятся в
  Redux.
- Первая реализация появляется в T-010, а не создаётся заранее.

## Последствия

- Формовое состояние отделено от серверного и глобального состояния.
- Правила валидации имеют явный проверяемый контракт.
- Исправимая ошибка не должна стирать введённые значения.
- Focus переводится к первой ошибке, сообщения связаны с полями доступным
  способом.
- React Hook Form и Zod устанавливаются только перед задачей, где они нужны, с
  подтверждением владельца.
