# ADR-003: CSS Modules и дизайн-токены

Дата: 2026-10-07. Статус: accepted. Подтверждено владельцем: 2026-10-07.

## Контекст

Lapka должна сохранять единый спокойный визуальный язык на mobile, tablet и
desktop. Полноценный внешний UI-kit и обязательный Figma-макет увеличили бы
объём учебного проекта, а глобальные стили компонентов создавали бы конфликты.

## Решение

- Компонентные стили пишутся в CSS Modules.
- Глобальный CSS содержит только reset, foundations, семантические токены и
  правила уровня приложения.
- Цвета, spacing, radii, typography, shadows и размеры иконок задаются CSS
  custom properties.
- Источник значений и адаптивных правил —
  `docs/product/04-design-spec.md`.
- Компоненты перестраиваются на контрольных диапазонах, а не дублируются
  отдельными mobile-версиями.
- Компонент дизайн-системы создаётся только при первом подтверждённом
  использовании.

## Последствия

- Стили компонентов изолированы, а визуальные решения централизованы в токенах.
- Служебная страница `/ui-kit` показывает реальный CSS и заменяет отдельный
  обязательный Figma UI-kit.
- Любое новое значение сначала сверяется с существующими токенами.
- Доступность, focus, reduced motion и контрольные ширины проверяются вместе с
  каждой задачей.
- CSS Modules и токены впервые реализуются в T-003.
