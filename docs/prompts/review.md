# Промпт: ревью витка

Скопируй этот текст после зелёного `npm run check`, до коммита.

```text
Сделай ревью текущего diff в Lapka. Код не переписывай.

Сверь diff со spec активной задачи, AGENTS.md, docs/ai-context/conventions.md
и ADR, на которые ссылается spec.

Проверь по порядку:
1. Критерии приёмки spec действительно закрыты, а scope не расширен.
2. Тест на критерий появился до реализации и падает без неё.
3. Нет выдуманных контрактов, цветов и зависимостей.
4. Нет секретов, реальных персональных данных, console.log и
   закомментированного кода.
5. Стили компонента лежат в CSS Module, значения взяты из токенов.

Формат ответа:
- замечания по серьёзности: корректность, доступность, лишний scope, стиль;
- что можно коммитить, если замечаний нет;
- какой один следующий шаг, если замечание есть.

Не объявляй виток принятым: принятие остаётся за владельцем.
```
