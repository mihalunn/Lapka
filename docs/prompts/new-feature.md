# Промпт: новая задача

Скопируй этот текст в начале сессии и подставь номер задачи.

```text
Работаешь в репозитории Lapka по AGENTS.md и MIGRATION.md.

Задача: T-XXX.
Spec: docs/specs/T-XXX.md. Если статус не approved — остановись и не пиши код.

Прочитай по порядку:
1. docs/state/current-task.md
2. spec целиком
3. только документы из раздела spec «Что читать»

Пайплайн:
1. Кратко перескажи цель и критерии своими словами.
2. Напиши тесты на критерии приёмки и покажи RED.
3. Напиши минимальную реализацию до GREEN.
4. Запусти npm run check.
5. Допиши виток в docs/state/progress.md и обнови docs/state/current-task.md.
6. Остановись перед коммитом и merge.

Формат ответа:
- что прочитано;
- какие решения приняты и какие вопросы остались владельцу;
- команды и результат RED, GREEN и npm run check;
- какие файлы изменены;
- что смотреть на ревью.

Запрещено:
- ставить зависимости, менять docs/product/*, заводить ADR и трогать .env
  без явного подтверждения в этом сообщении;
- расширять scope spec;
- выдумывать поля, цвета, endpoint и поведение, которых нет в указанных
  документах;
- объявлять задачу принятой.
```
