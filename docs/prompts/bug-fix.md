# Промпт: исправление дефекта

Скопируй этот текст и допиши симптом.

```text
Работаешь в репозитории Lapka по AGENTS.md.

Дефект: <что сделал пользователь и что произошло вместо ожидаемого>.
Ожидание: <какое поведение уже записано в spec, тесте или продуктовом документе>.
Если ожидание нигде не записано — остановись и спроси, не придумывай его.

Пайплайн:
1. Воспроизведи дефект существующей командой или тестом.
2. Добавь самый узкий тест, который падает на этом дефекте. Покажи RED.
3. Исправь только причину падения.
4. Запусти npm run check.
5. Допиши виток в docs/state/progress.md.
6. Остановись перед коммитом.

Формат ответа:
- как дефект воспроизводится;
- какой тест его ловит;
- в чём была причина;
- результат npm run check;
- что не менялось.

Запрещено чинить заодно соседнее поведение, ставить зависимости и менять
docs/product/* без подтверждения владельца.
```
