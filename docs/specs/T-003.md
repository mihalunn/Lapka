# Spec T-003: Перенести дизайн-токены

Статус: approved

## Цель

Заменить стартовые стили Vite на токены Lapka и показать их на одной служебной
странице. После задачи в браузере видны цвета, отступы, радиусы и шрифт из
дизайн-спецификации. Компоненты дизайн-системы, маршруты и данные питомцев не
входят в задачу.

## Критерии приёмки

- В глобальном CSS объявлены custom properties для каждой строки таблицы
  «Базовые токены» в `docs/product/04-design-spec.md`. Имена совпадают с
  таблицей, значения не заменены и не «улучшены».
- Демонстрационный блок на служебной странице берёт цвет, отступ, радиус и шрифт
  только через эти properties. В его CSS Module нет сырых цветов и пикселей из
  таблицы.
- Страница показывает все токены таблицы и остаётся читаемой на ширинах 390,
  768, 1024 и 1440 px, без горизонтальной прокрутки страницы.
- Контраст пар из таблицы проверен расчётом WCAG AA до реализации. Новые цвета
  не подбираются. `color-accent-500` на странице показан образцом заливки, а не
  цветом текста: на canvas и surface контраст около 2,5:1.
- `npm run check` проходит.
- В production-навигации этой страницы нет, потому что навигации продукта ещё
  нет. Страница заменяет стартовый экран Vite и не выдаёт себя за обзор семьи.

## Что НЕ трогать

- `docs/product/*`, ADR и `.env`.
- Зависимости, включая React Router и подключение Inter через пакет.
- Слои `widgets`, `features`, `entities`, `mocks`: для этой задачи они не нужны.
- Компоненты Button, Card и остальные из «Минимального набора».
- Тёмную тему. В спецификации её нет, стартовые стили Vite для
  `prefers-color-scheme: dark` не переносятся.
- Реальные имена людей, питомцев и медицинские сведения. Демонстрационный текст
  нейтральный: «Текст», «Поверхность», «Акцент».

## Проверка

1. Тест Testing Library: страница показывает подписи токенов из таблицы.
   Сначала RED на текущем стартовом экране Vite, затем GREEN.
2. `npm run check`.
3. Владелец открывает `npm run dev` и смотрит четыре ширины. Автоматический
   прогон ширин в этой задаче не требуется: браузерного сценария в репозитории
   нет.

## Риски / заметки

Маршрут `/ui-kit` из дизайн-спецификации появится вместе с маршрутизацией в
T-004. В T-003 служебная страница — единственный экран, без новой библиотеки.

Раздел «Foundations в коде» перечисляет success, warning, danger, тени, размеры
иконок и шкалу heading/title/body/label/caption. Чисел для них в таблице нет.
В T-003 эти properties не объявляются.

## Что уже решено для этой задачи

Вопросы ниже не требуют ответа владельца.

- Цвет текста на заливке `color-brand-600` в таблице не задан. Кнопки в T-003
  нет, поэтому свойство не объявляется. Для сведения: белый `#FFFFFF` на
  `#26736B` даёт около 5,6:1. Это не повод добавлять токен.
- `font-sans` — `Raleway, sans-serif`. Владелец заменил Inter 2026-11-27.
  Файл шрифта не кладётся в репозиторий: страница подключает Google Fonts.
  Если запрос шрифта не удался, браузер берёт `sans-serif`.
- Основной и вторичный текст, а также `color-brand-600` как текст, на canvas,
  surface и brand-100 проходят порог 4,5:1. `color-accent-500` как текст на
  canvas и surface не проходит. Образец акцента подписывается основным текстом.
