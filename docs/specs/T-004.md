# Spec T-004: Настроить маршрутизацию и AppLayout

Статус: in-progress

## Цель

Собрать каркас SPA: вложенный layout и клиентские переходы между разделами.
После задачи в браузере открываются `/overview`, `/pets/:petId`, `/calendar` и
`/family`. Данные питомцев, формы и остальные маршруты архитектуры в задачу не
входят.

## Критерии приёмки

- Установлен React Router. Пакет и версия показываются владельцу до установки.
  Без подтверждения пакет не ставится и код маршрутов не пишется.
- `/` перенаправляет на `/overview`.
- Доступны маршруты `/overview`, `/pets/:petId`, `/calendar`, `/family`.
  Страницы-заглушки показывают заголовки «Обзор», «Питомец», «Календарь»,
  «Семья». На странице питомца виден `petId` из URL. Любой непустой `petId`
  принимается: проверка существования питомца относится к T-008.
- Навигация содержит три ссылки: «Обзор» → `/overview`, «Календарь» →
  `/calendar`, «Семья» → `/family`. Логотип — текст «Lapka» и ведёт на
  `/overview`. Других пунктов нет.
- Активный пункт соответствует текущему пути и заметен двумя способами:
  `aria-current="page"` и отличие цветом уже объявленных токенов
  `color-brand-600` и `color-brand-100`. На `/pets/:petId` и на NotFound ни
  один пункт не активен.
- Неизвестный путь показывает заголовок «Страница не найдена» и ссылку
  «Обзор» на `/overview`.
- Переход по ссылке меняет адрес и содержимое без перезагрузки документа.
- Служебная страница токенов из T-003 доступна по `/ui-kit` и не входит в
  навигацию. Её тексты и набор токенов не меняются.
- На 1440 px навигация — постоянная колонка слева от контента. На 390 px —
  нижняя панель с теми же тремя ссылками. На 768 и 1024 px — свёрнутая левая
  панель с теми же тремя пунктами; подписи остаются в доступном имени ссылки.
- Оболочка читается на ширинах 390, 768, 1024 и 1440 px без горизонтальной
  прокрутки страницы. Область ссылки не меньше 44 × 44 px, focus заметен.
- `npm run check` проходит.

## Что НЕ трогать

- `docs/product/*`, ADR и `.env`.
- Redux Toolkit, RTK Query, React Hook Form, Zod и MSW.
- Маршруты вне результата T-004: `/pets/new`, `/pets/:petId/edit`,
  `/pets/:petId/entries/new`, `/pets/:petId/entries/:entryId`, `/events/new`,
  `/events/:eventId`. До своих задач они попадают в NotFound.
- Переключатель питомца, кнопки «Добавить запись» и «Запланировать», карточки,
  списки и приветствие. Для них нет данных и сценария в этой задаче.
- Пустые папки слоёв. Появляются только файлы с реальной ответственностью:
  маршрутизация, оболочка и страницы-заглушки.
- Тексты и токены служебной страницы. Меняется только место, где она
  подключена.

## Проверка

1. Показать владельцу имя и версию пакета React Router. Устанавливать после
   подтверждения.
2. Тесты Testing Library на критерии: четыре маршрута и видимый `petId`,
   активный пункт, NotFound, переход по ссылке без перезагрузки, `/ui-kit`
   по-прежнему показывает подписи токенов. Сначала RED, затем GREEN.
3. `npm run check`.
4. Владелец открывает `npm run dev` и смотрит четыре ширины. Автоматического
   прогона ширин в репозитории нет.

## Риски / заметки

Дизайн-спецификация для планшета допускает панель с иконками или временный
drawer. Владелец 2026-11-27 утвердил панель: активный пункт остаётся на экране,
отдельное состояние «меню открыто» не добавляется.

Верх контента из макета desktop — название раздела, переключатель питомца и
основное действие. В T-004 из этого остаётся только заголовок страницы.

## Что уже решено для этой задачи

- 2026-11-27 владелец утвердил spec и свёрнутую левую панель на 768 и 1024 px.
  Временный drawer в T-004 не делается.
