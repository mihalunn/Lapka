# Черновик решения: Lapka как семейное приложение

Дата: 2026-11-27. Статус: accepted. Подтверждено владельцем: 2026-11-27.

Этот файл не меняет `docs/product/*` и не заменяет ADR. Границы в продуктовых
документах остаются прежними, пока владелец отдельно не попросит их обновить.

## Зачем

Первая версия нужна не как демонстрация на собеседовании, а как приложение,
которым пользуются несколько конкретных людей: Михаил, жена, родители и брат.
Поддерживает его один человек. Клиент на этом этапе — адаптивный сайт.

## Готово, когда

Человек входит под своей учётной записью, открывает питомца с телефона,
добавляет запись истории или событие, и другой член этой же семьи видит
изменение после обновления страницы. Данные переживают закрытие браузера.

## В первой семейной версии

- одно семейное пространство и несколько питомцев;
- хронология типов `vet_visit`, `procedure`, `note`;
- события типов `vet`, `grooming`, `procedure`, `other`;
- одно вложение у записи;
- вход по почте для учёток, которые создаёт владелец;
- проверка доступа к семье на сервере;
- телефон через обычный браузер, в том числе Safari.

## Не входит

- отдельное приложение для Apple или Android;
- приглашения, роли, уведомления, PDF, тёмная тема;
- рекомендации, платежи, социальная сеть, чужие клиники;
- пустые архитектурные папки и правила агента без пользовательского результата.

Иконка сайта на домашнем экране iPhone допустима как действие пользователя в
Safari. Отдельная сборка для App Store не планируется.

## Как идём к этому

1. Закрыть Фазу 2: промпты и утверждённая spec T-003.
2. Сделать токены и служебную страницу foundations по T-003.
3. Собрать один читаемый экран семьи на моках, чтобы увидеть композицию.
4. Остановиться и выбрать хранение: одна управляемая база, вход по почте,
   хранилище одного вложения, резервная копия. Это отдельное решение владельца,
   не часть сегодняшнего черновика.
5. Дальше наращивать только сценарий «увидел питомца → записал → другой увидел».

Моки остаются честным ограничением, пока нет сервера: перезагрузка стирает
изменения. Семейное пользование начинается только после шага 4.

## Что остаётся в силе

`MIGRATION.md`, ADR-001 — ADR-004 и запрет выдумывать контракты. Стек фронтенда
не пересматривается этим черновиком. Бэкенд по-прежнему не выбран.
